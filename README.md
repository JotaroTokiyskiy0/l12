## Установка и запуск

### Локальный запуск

1. Перейдите в папку проекта:
   ```bash
   cd fitness_platform
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Запустите приложение:
   ```bash
   uvicorn app.main:app --reload
   ```

4. Откройте в браузере: http://127.0.0.1:8000

### Запуск через Docker

1. Соберите и запустите контейнеры:
   ```bash
   docker-compose up --build
   ```

2. Приложение будет доступно по адресу: http://127.0.0.1:8000

## Пользовательский интерфейс

После запуска приложения откройте в браузере http://127.0.0.1:8000.
Вы попадёте на веб-страницу, где можно:

- **Просматривать** список всех упражнений
- **Добавлять** новые упражнения через форму
- **Редактировать** существующие упражнения (кнопка ✏️)
- **Удалять** упражнения (кнопка 🗑️)

Все действия отправляют запросы к API в реальном времени.

Документация API (Swagger) доступна по адресу: http://127.0.0.1:8000/docs

## API-эндпоинты

| Метод | Путь                 | Описание                          | Код ответа |
|-------|----------------------|-----------------------------------|------------|
| GET   | `/exercises`         | Получить список упражнений        | 200        |
| POST  | `/exercises`         | Создать новое упражнение          | 201        |
| GET   | `/exercises/{id}`    | Получить упражнение по ID         | 200        |
| PUT   | `/exercises/{id}`    | Обновить упражнение               | 200        |
| DELETE| `/exercises/{id}`    | Удалить упражнение                | 204        |

### Параметры запросов

**GET /exercises** поддерживает опциональные параметры:
- `skip` (int) — сколько записей пропустить (по умолчанию 0)
- `limit` (int) — сколько записей вернуть (по умолчанию 100)
- `category` (str) — фильтр по категории

### Примеры запросов

#### Создание упражнения

```bash
curl -X POST "http://127.0.0.1:8000/exercises" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Бег",
    "description": "Кардио нагрузка",
    "category": "кардио",
    "difficulty": "лёгкий",
    "calories_per_hour": 500.0
  }'
```

Ответ (201):

```json
{
  "id": 1,
  "name": "Бег",
  "description": "Кардио нагрузка",
  "category": "кардио",
  "difficulty": "лёгкий",
  "calories_per_hour": 500.0
}
```

#### Получение списка упражнений

```bash
curl -X GET "http://127.0.0.1:8000/exercises?category=силовая&limit=2"
```

Ответ (200):

```json
[
  {
    "id": 2,
    "name": "Жим лёжа",
    "description": "Базовое силовое упражнение",
    "category": "силовая",
    "difficulty": "средний",
    "calories_per_hour": 300.0
  }
]
```

#### Получение упражнения по ID

```bash
curl -X GET "http://127.0.0.1:8000/exercises/1"
```

Ответ (200):

```json
{
  "id": 1,
  "name": "Бег",
  "description": "Кардио нагрузка",
  "category": "кардио",
  "difficulty": "лёгкий",
  "calories_per_hour": 500.0
}
```

#### Обновление упражнения

```bash
curl -X PUT "http://127.0.0.1:8000/exercises/1" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Бег (интервальный)",
    "calories_per_hour": 650.0
  }'
```

Ответ (200):

```json
{
  "id": 1,
  "name": "Бег (интервальный)",
  "description": "Кардио нагрузка",
  "category": "кардио",
  "difficulty": "лёгкий",
  "calories_per_hour": 650.0
}
```

#### Удаление упражнения

```bash
curl -X DELETE "http://127.0.0.1:8000/exercises/1"
```

Ответ: 204 No Content

#### Ошибка 404 (не найдено)

```bash
curl -X GET "http://127.0.0.1:8000/exercises/999"
```

Ответ:

```json
{
  "detail": "Exercise with id 999 not found"
}
```
